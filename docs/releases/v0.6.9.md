Marking an R1 lost now locks Android even on R1s whose Android has no device-admin support, which
is most of them.

- **Lockdown through root.** Where device admin isn't available, robotOS locks with Android's own
  lockdown, the power menu's "Lockdown": the R1 locks at once and needs its screen lock. Device
  admin is still used where Android supports it. Either way, Android's screen lock must be set.
- **The return message stays visible.** A lost R1's page, with your return message and **Stop
  ringing**, now shows on top of Android's lock screen, so whoever finds it can still read how to
  return it. robotOS's own content stays hidden behind the cover.
- **No dead button.** On builds without device admin, **Host & devices** no longer offers "Enable
  Android device admin". On those builds Android accepts the request and silently ignores it, so
  the button did nothing.

App update only. The hub and Hermes tools are unchanged.

Automated tests cover the following:
- lockdown through root when device admin is missing;
- no remote lock without a screen lock, or without both device admin and root;
- lost mode locking through root;
- the lost page showing over the lock screen, and stopping once the R1 is restored.

On a physical R1 with a pattern lock, the lockdown command locked Android at once and required the
pattern.
