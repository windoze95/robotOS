Android's lock screen now matches robotOS: it shows the robot mark glowing on black, like the
recovery cover, so swiping up to unlock looks like swiping the cover away. robotOS sets this
wallpaper once. If you pick another in Android's settings, robotOS never replaces it.

robotOS now says "screen lock" wherever it said "PIN", because a pattern or password works just as
well. The recovery screen's option is now **Open with your screen lock**.

INSTALL.md's "Lock it with a screen lock" setup now covers what the first version missed:
- **Lock after screen timeout** recommends 5 minutes, an option Android actually offers.
- **Power button instantly locks** is explained: robotOS's tap-to-sleep counts as a press of the
  power button.
- What device admin is used for, and how to turn it off.
- How to check the setup took: **Host & devices** shows "Protection: robotOS restriction and
  Android secure lock".
- The limits of a screen lock on a rooted R1 with an unlocked bootloader.

App update only. The hub and Hermes tools are unchanged.

Automated tests cover the following:
- the wallpaper being applied only once;
- the rendered lock screen being black at the edges with the orange glow around the mark.
