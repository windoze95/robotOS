Hermes can open robotOS screens on the R1 with the new `open_app` tool: Home, Workspace, Notes,
Prompt Builder, Chats, Messages, Hermes, Settings, Quick controls, Updates and Host & devices.
Notes and Prompt Builder accept an optional exact `item_id` to open a saved note or prompt.
Shared items are fetched if they have not reached the R1 yet. Opening a prompt only shows its
detail; it does not run it or acquire an edit lease.

Enable **Menu → Hermes → Open apps on screen** after updating; the permission starts off.
The R1 must be awake, unlocked and showing robotOS. Active recordings, unsaved note edits and
approval reviews prevent navigation. Repeated requests with the same ID recover the original
receipt without navigating again.

Update the robotOS hub and the Hermes MCP adapter/robotOS skill alongside the Android app to
advertise and route the new tool. Existing credentials and device permissions are retained.

Automated tests cover permissions, app destinations, saved-item navigation, shared-note fetching,
request replay, busy/locked-device behavior and hub routing. Physical R1 acceptance has not been performed for
this change.
